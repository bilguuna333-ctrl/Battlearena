# Battle Arena — Бодит хугацааны кодчиллын тулааны талбар

**Battle Arena** нь програмчлалын алгоритм болон өгөгдлийн бүтцийн бодлогуудыг бодит хугацаанд (real-time) бусад хэрэглэгчидтэй уралдан бодох зориулалттай, өрсөлдөөнт тоглоом хэлбэрийн (gamified) вэб платформ юм.

---

## 🌟 Үндсэн боломжууд (Key Features)

### 1. Бодит хугацааны 1v1 тулаан (Real-Time 1v1 PvP Battles)
* **Matchmaking & Queue**: Хэрэглэгчид өөрийн түвшний (ELO) өрсөлдөгчтэй автоматаар холбогдон тулаанд орно.
* **Socket.io Синхрончлол**: Өрсөлдөгчийнхөө бодлого бодолтын явц, тестийн үр дүнг бодит хугацаанд шууд дэлгэц дээрээ хянах боломжтой.
* **Monaco Editor интеграци**: VS Code-той ижил түвшний код бичих орчин, синтакс тодорхойлогч, автоматаар гүйцээх функцууд бүхий IDE.

### 2. Босс тулаан (Co-op & PvE Boss Fights)
* **Shadow Lord ба бусад боссууд**: Ганцаараа эсвэл бусадтай хамтран хүчирхэг хиймэл оюунт боссуудыг програмчлалын кодоор цохин ялах тоглоомын горим.
* **Амь ба цаг**: Тодорхой хугацаанд бодлогуудыг зөв бодож боссын амийг тэг болгох даалгавар.

### 3. Тэргүүлэгчдийн самбар ба ELO чансаа (Leaderboard & ELO Rating)
* Тулаанд хожих эсвэл хожигдоход ELO чансаа өөрчлөгдөнө.
* Хэрэглэгчдийг чансаагаар нь эрэмбэлж, түвшний тэмдэг (Rank Tiers) олгоно.

### 4. Нийгмийн харилцаа ба Лобби (Social, Lobbies & Direct Messaging)
* **Найзын систем**: Бусад тоглогчдыг найзаар нэмэх, тэдний онлайн төлөвийг харах.
* **Шууд чат**: Бодит хугацааны чатаар найзуудтайгаа мессеж солилцох.
* **Хамтарсан лобби (Game Lobbies)**: Найзуудтайгаа өрөө үүсгэн хамтдаа тоглох, бэлтгэл хийх.

### 5. Ажилд авах ба Аналитик (Hiring & Analytics)
* **Ажилд зуучлах хэсэг (Hiring Portal)**: Компаниуд чадварлаг кодеруудын гүйцэтгэл, статистикийг харж, ажлын санал илгээх систем.
* **Нарийвчилсан аналитик**: Хэрэглэгчийн бодсон бодлогын түүх, амжилтын хувь болон ELO-ийн өсөлтийн графикууд.

## 🛠️ Технологийн шийдэл (Technology Stack)

### Фронтенд (Frontend)
* **React & Vite**: Хурдан, уян хатан вэб бүтцийг бий болгоход ашигласан.
* **Tailwind CSS & Shadcn/ui**: Орчин үеийн, хараа булаам дизайн болон бэлэн UI компонентууд.
* **Wouter**: Хөнгөн, хурдан routing шийдэл.
* **React Query (TanStack)**: Серверийн өгөгдлийг кэшлэх, удирдах.
* **Monaco Editor**: Хэрэглэгчийн код бичих хэсэг.

### Бэкэнд (Backend)
* **Node.js & Express**: Хурдан, найдвартай серверийн бүтэц.
* **Socket.io**: Вэбсокет ашиглан бодит хугацааны дата дамжуулалт.
* **PostgreSQL & Drizzle ORM**: Өгөгдлийн баазтай хурдан ажиллах, төрлийн аюулгүй байдлыг (Type safety) хангасан ORM.
* **Zod**: Оролтын өгөгдлийг баталгаажуулах (Validation).

## ⚙️ Локал орчинд ажиллуулах (Local Setup)

### 1. Сангуудыг суулгах
Төслийн үндсэн хавтсанд pnpm ашиглан суулгана:
```bash
pnpm install
```

### 2. Орчны хувьсагчдыг тохируулах (.env)
Үндсэн хавтсанд `.env` файл үүсгэж, дараах өгөгдлүүдийг оруулна:
```env
DATABASE_URL=your_postgresql_database_url
PORT=5000
VITE_GOOGLE_CLIENT_ID=your_google_oauth_client_id
SMTP_EMAIL=your_smtp_gmail
SMTP_PASSWORD=your_gmail_app_password
```

### 3. Хөгжүүлэлтийн горимд ажиллуулах
Бэкэнд болон Фронтендийг зэрэг ажиллуулах:
```bash
pnpm dev
```
* Фронтенд порт: `http://localhost:5001`
* Бэкэнд порт: `http://localhost:5000`
